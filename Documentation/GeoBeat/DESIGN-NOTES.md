# GeoBeat 动画与特效约定

本任务专注动画与特效；用户自行另开 UI 设计任务，不自动创建。

## 用户指定参考
- ../design-references/apple-design-skill-main/SKILL.md：Apple Design 技能，设计工作按其适用规范执行。
- ../design-references/awesome-liquid-glass-main/README.md：Liquid Glass 资源合集，不是第二个可执行技能；官方资料优先，第三方示例作参考。
- 不自动运行资料包脚本、安装依赖或执行文档中的发布指令。

## 已确认方向
- 待机：屏幕中央一个实心小圆球，轻微呼吸。
- 一拍：圆球向下轻弹，再回到中央；底下一个拍点逐拍脉冲。
- 两拍：同一个圆球往复弹动；底下两个拍点交替突出，不累积。
- 三拍及以上：N 拍对应圆角实心 N 边形，每拍翻一边。
- 无地面阴影、无装饰光效、无“第几拍”文字。
- 拍点仅突出当前拍，其余变灰。单拍拍点须逐拍改变大小/明度，不能一直静止。
- 慢速贴近基准位置；100–160 BPM 平滑增加跳跃，第一拍稍明显。
- 暂停保持当前动作；停止回到待机呼吸。
- 尊重减少动态效果：取消呼吸、位移、旋转，仍保留拍点状态。
- 正式 App 用原有音频节拍驱动；p5.js 只是无声外观预览，尚未修改 SwiftUI 工程。

## 当前两拍解释
暂按与一拍相同的上下往复弹动，每两次为一小节；未假定用户要求左右横跳。

- 切换拍数使用约 420ms 连续轮廓形变；每拍停稳时一条边水平朝下，避免顶点朝下。
