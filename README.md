# GeoBeat / 节拍打卡 V5.2

一个面向 iPhone 与 iPad 的自用 SwiftUI 练习打卡 + 可视节拍器 App。

## 已实现

- 新建、自命名、编辑和删除练习事件。
- 练习事件支持一级目录管理，可新建、改名、移动项目或删除目录；删除目录只会把项目移回“未分类”，不会删除练习项目及其历史。
- 创建或编辑事件时可开启长期练习目标，并分别设置左手、右手、合手目标；当天首次从该事件开始练习时可单独确认今日目标，同日后续练习会自动沿用并累计进度。
- 有今日目标时，节拍器的 `+1` 计数显示为 `已完成/目标`；完成页同时展示三手目标、已完成、剩余、完成率和完成状态，并区分今日目标与长期计划进度。
- 练习完成后可将结构化结果卡保存到相册；导出内容包含事件、日期、三手统计、速度摘要以及今日/计划目标进度，而不是截取当前页面。
- V5.2 主界面以正多边形生命周期为视觉中心：等待时只有中心小球；首次运行按每个主拍逐边构建 N 边形，完成后保持完整，小球由真实节拍事件驱动并在一小节内沿周界循环一圈。
- 运行舞台采用稳定的扫视层级：当前主拍以持续实心定位点保持第一优先级，其次显示完整“基准音符 = BPM”，再显示拍数/分组、训练音符、手型与节拍运行状态；矮屏会切换为单行摘要而不会隐藏这些信息。
- 拍数只决定边数，训练音符只决定每小节声音与视觉事件密度，BPM 决定时间，重音结构决定 Hit 力度；细分事件不会增加边。点击“练习完毕”后小球先回到中心，再按构建的逆序逐边解构。
- 页面底部是一块统一的圆润玻璃控制面板：3–9 拍只显示相邻值；BPM 基准音符与数值以“音符 = 数字”独立滑动；训练音符、`L / B / R`（左手 / 合手 / 右手）与当前手型 `+1` 融合在同一材质中；新会话默认选择 `B`。
- V4.1 使用更短促、更有穿透力的程序化节拍声，整体可听度显著提高，同时保留主拍、组重音、普通拍和细分的四级层次与安全峰值上限。
- iOS 26 使用系统 Liquid Glass，iOS 17–25 使用原生 Material 毛玻璃回退；“降低透明度”开启时使用高对比实色回退。
- 新建事件只填写名称与节拍器预设；练习统计统一在节拍器会话中完成。
- 进入节拍器后默认使用合手模式并自动计时，可切换左手、右手或合手。
- 切换手型时结算当前计时段并重新计时，支持确认提示和“不再提示”偏好。
- 在节拍器中每次 `+1` 都会按左手、右手或合手保存当时的完整节拍器设置，并自动累计各手型的次数与练习时长；`-1` 撤销该手最近一次完成记录。
- “练习完毕”会展示三种手型的次数、时长、“练习最多”和“最大尝试”；确认后以追加方式保存历史，并在真正落库后明确显示成功或失败。
- 每个事件按手型保留历次练习记录，可查看最近及完整历史，并可从“练习最多”对应记录继承 BPM、基准音符、训练音符、拍数、分组和方向。
- 会话会定期保存本地草稿（含当前节拍器预设）；锁屏或切到其他 App 时可选择让节拍声与计时继续，音频中断时会同步暂停并保存；待确认的完成汇总也可恢复。
- 每个事件保存一份完整节拍器预设快照：BPM、BPM 基准音符、拍数、重音分组、训练音符和闪烁顺序。
- 新建事件可继承当前节拍器、内建慢/中/快预设，或任一已有事件的预设。
- 30–240 BPM；BPM 基准支持二分、四分、八分音符及其附点；训练音符支持二/四/八/十六分；另有 3–9 拍、顺/逆时针，以及 5 拍和 7 拍的条件分组。
- 速度标题同时显示意大利语与数值，例如 `Moderato · 112 BPM`。
- BPM 支持 ±1、横向或纵向滑动以及双击数字直接输入；拖动数字时所属页面保持固定，拖动中就地预览、松手后一次性应用。拍数、训练音符和手型轨道同样支持连续拖选，界面不使用速度进度条。
- “调速、声音与屏幕”中可选择 BPM 滑动方向，并可独立设置锁屏/后台继续节拍声（默认开启）与节拍播放时保持屏幕常亮（默认关闭）。
- 播放中调整 BPM 或基准音符时保持当前拍位连续；已经排入音频队列的脉冲正常完成，新速度从后续节拍边界平滑生效，不回到第一拍。
- SwiftData 本地持久化；无需账号或网络。
- iPhone / iPad / 分屏与横屏自适应布局，画布始终保持比例。
- “减弱动态效果”“调暗闪烁光线”适配与 VoiceOver 标签。

## 打开与构建

直接双击 `GeoPractice.xcodeproj`，或在终端运行：

```sh
open GeoPractice.xcodeproj
```

工程最低支持 iOS/iPadOS 17，目标设备族包含 iPhone 和 iPad。首次运行请选择一个 iOS Simulator；真机运行时，在 Xcode 的 Signing & Capabilities 中选择你自己的 Team。

如果 Xcode 工具栏显示 `iOS … Not Installed`，点击旁边的 `Get`，或进入 **Xcode → Settings → Components** 安装一个 iOS Simulator runtime。runtime 安装完成后即可选择 iPhone/iPad 设备并运行测试。

## 实现说明

V5.2 中央舞台依据《正多边形构建与循环节奏视觉系统》重构；音频调度仍是唯一时间源，视觉只消费主拍、细分、小节和呈现时间，不反向驱动 BPM。界面为 SwiftUI 原生实现，未照搬需求包中的示例代码。

源码使用 Git 管理：`v3` 标签保存第三版基线，第四版开发位于 `v4-design` 分支。

数据只保存在本机 App 沙盒。删除事件前会二次确认。
